Смена пароля

Страница для автора. Пароль меняется прямо в браузере: на сервер ничего не отправляется. Сами материалы перешифровывать не нужно, меняется только файл ключей.

Готово. Осталось сохранить новый файл ключей на GitHub:
  1. Нажмите «Скопировать» под полем ниже.
  2. Откройте в репозитории файл assets/full/keys.json и нажмите значок карандаша (Edit).
  3. Удалите всё содержимое, вставьте скопированный текст и нажмите «Commit changes».
  4. Через 1–2 минуты сайт обновится. Новый пароль:

После смены все устройства, где входили со старым паролем, потеряют доступ: на них нужно будет ввести новый пароль.
