# Сайт «Математическая экология»

Статический сайт: не нужны сервер, база данных или сборка. Его можно открыть двойным щелчком по `index.html` или разместить на любом хостинге.

## Структура

```
index.html                  — страница сайта
assets/css/style.css        — оформление
assets/js/i18n.js           — тексты интерфейса на русском и казахском
assets/js/data.js           — содержание: разделы, 34 занятия, документы,
                              69 задач, экскурсии, результаты, отзывы
assets/js/app.js            — работа страницы (вкладки, фильтры, окно «На экран»)
assets/img/                 — иллюстрации из рабочей тетради
assets/covers/              — обложки документов
assets/author.jpg           — фото автора
assets/preview/             — страницы-фрагменты документов, открыты всем
assets/full/                — все страницы документов в зашифрованном виде
assets/full/keys.json       — ключ, зашифрованный паролем (меняется при смене пароля)
tools/smena-parolya.html    — страница для смены пароля
```

## Как изменить содержание

* **Текст на странице:** найдите фразу в `assets/js/i18n.js`. У каждой фразы есть русский (`ru`) и казахский (`kz`) вариант.
* **Задачи, занятия, экскурсии, цифры апробации:** всё лежит в `assets/js/data.js`.
* **Контакты для запроса полных версий:** заполните `CONTACT` в `assets/js/data.js` (почта, телефон, WhatsApp). Пока поля пустые, на сайте показывается обращение в КГУ «Инновационный центр развития образования».
* **Доступ к полным версиям.** Без пароля видны только фрагменты. С паролем от автора в окне просмотра открываются все страницы. Скачать документы нельзя, можно только листать. Пароль запоминается на устройстве, пока не нажать «Закрыть доступ на этом устройстве». Регистр букв и дефисы в пароле не важны.
* **Смена пароля:** откройте на сайте страницу `tools/smena-parolya.html`, введите текущий и новый пароль и вставьте полученный текст в файл `assets/full/keys.json` на GitHub. После смены все устройства, где входили со старым паролем, потеряют доступ. Сами страницы при этом не перешифровываются: если пароль попал в чужие руки и важно надёжно отрезать доступ, материалы лучше перешифровать заново.
* **Фрагменты документов:** страницы лежат в `assets/preview/` как `<документ>-1.webp`, `<документ>-2.webp` и т. д.; число страниц во фрагменте задаёт поле `preview` в `MATERIALS`. Полные PDF в репозиторий не добавляйте: репозиторий публичный, и любой сможет их скачать.

* **Статистика посещений (Google Analytics 4):** впишите идентификатор потока данных вида `G-XXXXXXXXXX` в `ANALYTICS.ga4` в `assets/js/data.js`. Пока поле пустое, статистика не собирается. Кроме посещений считаются события: `open_fragment`, `open_full_document`, `password_success`, `password_fail`, `access_closed`, `show_answer`, `task_on_screen`, `random_task`, `open_excursion`, `open_plan_section`, `switch_language`. Какой документ, задача или маршрут — в параметре `content_id`. Пароль и личные данные не передаются.

Открыть сайт сразу на казахском можно по ссылке с `?lang=kz` в конце адреса, например `index.html?lang=kz`.

## Как опубликовать

Подойдёт любой хостинг статических сайтов, например:

* **Netlify Drop** (app.netlify.com/drop): перетащите папку сайта в окно браузера и получите ссылку.
* **GitHub Pages:** сайт уже публикуется автоматически через GitHub Actions (`.github/workflows/pages.yml`) при каждом изменении ветки `main`.
* **Хостинг школы или организации:** скопируйте всю папку целиком, сохранив структуру.
