# Сайт «Математическая экология»

Статический сайт: не нужны сервер, база данных или сборка. Его можно открыть двойным щелчком по `index.html` или разместить на любом хостинге.

## Структура

```
index.html                  — страница сайта
assets/css/style.css        — оформление
assets/js/i18n.js           — тексты интерфейса на русском и казахском
assets/js/data.js           — содержание: разделы, 34 занятия, документы,
                              69 задач, экскурсии, результаты, отзывы
assets/js/app.js            — работа страницы (вкладки, фильтры, окно «На экран»)
assets/img/                 — иллюстрации из рабочей тетради
assets/covers/              — обложки документов
assets/author.jpg           — фото автора
materials/*.pdf             — документы программы для просмотра и скачивания
```

## Как изменить содержание

* **Текст на странице:** найдите фразу в `assets/js/i18n.js`. У каждой фразы есть русский (`ru`) и казахский (`kz`) вариант.
* **Задачи, занятия, экскурсии, цифры апробации:** всё лежит в `assets/js/data.js`.
* **Новый документ:** положите PDF в `materials/`, добавьте запись в `MATERIALS` в `data.js` и картинку обложки в `assets/covers/`.

Открыть сайт сразу на казахском можно по ссылке с `?lang=kz` в конце адреса, например `index.html?lang=kz`.

## Как опубликовать

Подойдёт любой хостинг статических сайтов, например:

* **Netlify Drop** (app.netlify.com/drop): перетащите папку сайта в окно браузера и получите ссылку.
* **GitHub Pages:** загрузите файлы в репозиторий и включите Pages в настройках.
* **Хостинг школы или организации:** скопируйте всю папку целиком, сохранив структуру.
